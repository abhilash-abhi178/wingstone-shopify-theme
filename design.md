# Wingstone Stitch Design Brief

Design a premium Shopify storefront UI for Wingstone that feels cinematic, cool-toned, and editorial rather than generic ecommerce.

## Brand Direction

- Tone: luxurious, minimal, polished, and high-contrast.
- Mood: dark cinematic surfaces with frosted layers, subtle depth, and deliberate motion.
- Visual language: soft borders, restrained shadows, glassy panels, and spacious layouts.
- The interface should feel premium on desktop and touch-friendly on mobile.

## Color System

Use the Wingstone theme tokens as the source of truth.

- Ink navy: `#04102f`
- Frost: `#f9f9ff`
- Steel: `#5a6a8a`
- Paper: `#ffffff`
- Line: `#D5DDEA`
- Accent: `#c8a96e`

Use accent colors sparingly for emphasis, CTAs, badges, and key highlights. Keep most surfaces quiet and neutral.

## Typography

- Headings: Georgia, serif
- Body: Assistant, system-ui, sans-serif
- Preserve a strong editorial hierarchy.
- Use restrained uppercase labels for utility text, navigation labels, and metadata.

## Layout Principles

- Prefer generous spacing and clearly separated sections.
- Build layered backgrounds rather than flat blocks of color.
- Keep content centered within a comfortable maximum width.
- Use asymmetry only when it improves hierarchy and flow.
- Make mobile layouts collapse cleanly without losing premium feel.

## Key Screens To Design

Create the core storefront screens and states:

- Homepage
- Collection / category listing
- Product detail page
- Cart drawer / cart page
- Search results
- Account / login
- Editorial content pages
- Empty, loading, and error states

## Component Style

- Buttons: bold, clear, and easy to tap.
- Cards: consistent radius, padding, and spacing.
- Forms: clean inputs with strong focus states.
- Chips / badges: compact, legible, and restrained.
- Drawers and modals: layered overlays with smooth transitions.
- Tables and filters: readable, compact, and efficient.

## Ecommerce Behavior

- Product cards should support quick add without visual noise.
- Cart interactions should feel immediate and polished.
- State changes should be obvious through badges, counters, and subtle motion.
- Keep the path to purchase obvious at every step.

## Motion

- Use subtle easing and purposeful transitions.
- Animate only key moments such as section reveals, drawer open/close, and button feedback.
- Avoid playful or bouncy motion.

## Accessibility

- Maintain strong text contrast on every surface.
- Make all interactive controls keyboard accessible.
- Ensure touch targets are comfortable on mobile.
- Keep labels, states, and feedback clearly distinguishable.

## Stitch Prompt Guidance

When generating screens, prioritize:

- Premium Shopify storefront aesthetics
- Strong product storytelling
- Editorial composition with commercial clarity
- Cool-toned cinematic styling
- Responsive behavior across desktop and mobile

Avoid:

- Generic SaaS layouts
- Bright saturated palettes
- Overly playful motion
- Dense, cluttered interfaces
- Flat white-on-white screens

## Output Expectation

Produce screens that look ready for a luxury ecommerce brand, with reusable component patterns that can be applied consistently across the full storefront.
